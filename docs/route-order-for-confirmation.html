Two questions, and they are the whole point of this note

Is this the order work actually flows in?

Your capacity sheet listed these departments across the top of the page, but a column order is a layout, not a sequence. We put them in the order the trade normally runs. If anything is out of place — particularly around the finishes — move it.

Does anything here run alongside something else?

Metal Finishing and Fiber Processing look to us like feeder operations that happen while the wood line is running, rather than after it. Kram currently treats the route as one line, so we need to know where that is untrue.

What the position number doesAnd what it does not

The number is only a sequence. It does not set any dates. Every deadline comes from the D-minus figure — how many days before the container stuffing date that department has to be finished — and those you enter yourself, per product, per department.

What the order does decide is which department Kram treats as the one before. That is how it warns you when a department is being asked to start before the step feeding it has finished — a problem overtime cannot solve, because the work simply is not there yet.

So an order that is wrong will not give you wrong dates. It will give you warnings that are not real, and miss ones that are.

One rule that keeps the two agreeing

A department that has to finish earlier should sit earlier in the route. If Metal Finishing must be done by D-40 and Wood Finishing by D-30, then Metal Finishing belongs above Wood Finishing in this list.

Kram checks this for you. If you enter a D-minus that contradicts the order, it says so on the capacity sheet and names both departments. It will not change anything on your behalf — which of the two figures is wrong is your call, not the software's.

Changing it

  1. Sign in and open Masters.
  2. In Production route, the first column is the position number. Click it, type a new one, press Enter.
  3. Use the tens — 10, 20, 30 — so there is always room to drop a department between two others later without renumbering everything.
  4. Nothing else needs doing. The schedule recalculates as soon as you change it, and the effect is visible on the next screen you open.

What we need back

The corrected order, and a note of anything that runs in parallel. The second one matters more than it sounds: if two departments genuinely work at the same time rather than one after the other, we would rather change how Kram models the route than have you work around it.
